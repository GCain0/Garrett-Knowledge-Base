# The Alola Region

Alola is a tropical region inspired by Hawaii, introduced in Generation VII. It features island trials instead of traditional Gyms and introduced regional forms.

## Geography

Alola includes:

- Four main islands  
- Volcanoes  
- Beaches  
- Rainforests  
- Coral reefs  

## Major Features

- **Island Trials** — Replaces Gyms.  
- **Totem Pokémon** — Strong boss Pokémon.  
- **Regional Forms** — New versions of classic species.

## Native Pokémon

- Rowlet  
- Litten  
- Popplio
